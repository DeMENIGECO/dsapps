FERDOR DEVELOPER

Fare Addon per Ferdor e Ferdor Beta

Guida per sviluppatori per creare addon, utilizzare E++ e aggiungere logiche avanzate a Ferdor.

📘 Guida per sviluppatori
Questa guida è dedicata agli sviluppatori che vogliono creare addon per Ferdor e Ferdor Beta.

🧩 Introduzione

Gli addon permettono di estendere le funzionalità di Ferdor aggiungendo nuove funzioni, automazioni e comportamenti.

Per creare logiche più avanzate puoi utilizzare E++, il linguaggio utilizzato dagli addon Ferdor.

⚡ Guida E++

E++ è un linguaggio avanzato pensato per gli addon di Ferdor.

I file E++ utilizzano l'estensione: ADDON-EPP

Con E++ puoi creare:

  • ⚙️ Automazioni
  • 📦 Moduli
  • ⚡ Eventi
  • 🧠 Logiche interne
  • 📁 Gestione dei file
  • 🐞 Debug

📖 Guarda anche: Come programmare in E++

🏗️ Struttura base

Un file E++ può partire da una struttura simile a questa:

E++ 
\ E++ File.Name "base"
\ File includemdl <basestudio>, <eppinit>

<eppinit>.InitMdl[this]
