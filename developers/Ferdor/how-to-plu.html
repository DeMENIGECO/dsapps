FERDOR DEVELOPER

Fare Addon per Ferdor e Ferdor Beta

Guida passo-passo per creare, impacchettare e inviare un'estensione per Ferdor.

🧩 Guida per sviluppatori
Questa guida è dedicata agli sviluppatori di addon per Ferdor e Ferdor Beta.

🚀 Procedimento

1Crea la cartella

Crea una cartella con il nome che vuoi, ad esempio my-extension.

Ti consigliamo di utilizzare un nome corto, semplice e memorabile: sarà il nome in codice dell'estensione.

2Crea il file INFORMATION

All'interno della cartella crea un file chiamato INFORMATION.

INFORMATION 
meta {author {"tuonome"}; prod {"La Mia Estensione"};}
build {prod.build {aa.numeroversione}}
superusr {enabled {False}}
setuptools {actived {False}}

3Crea il file SETUP

Crea quindi il file SETUP. Questo file contiene le informazioni necessarie alla configurazione dell'addon.

SETUP 
file {
    dir:{th.thisuserwithferdor + "my-extension.plu" #Sostituisci 'my-extension' con il nome in codice
    }
}

4Crea il file ADDON

Il file ADDON contiene il binario dinamico dell'estensione.

⚠️ Attenzione
Inserisci il contenuto binario fornito dalla documentazione nel file ADDON.
BINARY 
50 6C 67 8A F3 21 9C 4D 7B C2 D4 19 8E 55 3A C7
0F B2 6D 91 A1 3F 77 C8 92 4B 0D E6 11 5A 9C 73
2E B4 F0 6A 88 12 4D AF 39 C1 7E 55 90 2B DC 61
08 F3 9A 47 5C E2 14 78 AB 6F 33 D0 9E 01 4A B7
C5 2D 88 F1 6C 90 3E 72 19 AD 5F C0 27 81 EA 44
68 B2 0F 95

5Impacchettazione

Seleziona tutto il contenuto della cartella utilizzando:

  • CTRL + A su Windows/Linux
  • COMMAND + A su macOS

Comprimi quindi i file in un archivio ZIP e rinominalo utilizzando il nome in codice dell'estensione con estensione .plu.

FILE
nome-in-codice.plu

6Invia l'addon

Quando hai completato l'addon, puoi inviarlo tramite email.

✉️ Invia estensione

✅ Prima dell'invio

📎 Ricorda

  • Allega il file .plu.
  • Sostituisci "Nome" nell'oggetto dell'email.

🛡️ Rispetta le regole

  • Non creare contenuti pericolosi.
  • Gli addon che violano le regole non verranno pubblicati.

⏱️ Tieni a mente

  • La revisione potrebbe richiedere qualche ora o qualche giorno.
🚀 Fatto!
Dopo aver inviato l'estensione, attendi la revisione. Se l'addon rispetta i requisiti, potrà essere aggiunto agli addon disponibili per Ferdor.
